# Profile Components

Composants du profil utilisateur et du profil de peau.

## Composants

### `SkinProfileCard.tsx`
Carte récapitulatif du profil beauté: type peau (visage/corps/cheveux) + top 3 préoccupations.

### `BeautyProfileForm.tsx`
Formulaire complet éditable reprenant les mêmes champs que l'onboarding.
Avec auto-save debounce.
