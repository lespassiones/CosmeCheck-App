# Shared Components

Composants partagés utilisés dans toute l'application CosmeCheck.

## Composants

### `Logo.tsx`
Logo "Cosme Check" avec texte + icône flacon. Tailles: sm/md/lg.

### `SearchBar.tsx`
Barre de recherche avec debounce, icône loupe et placeholder animé.

### `ConfirmDialog.tsx`
Modal de confirmation avec titre, message et boutons Annuler/Confirmer.

### `ProcessingOverlay.tsx`
Overlay plein écran avec spinner et message "Analyse en cours...".

### `CreditsPill.tsx`
Pilule affichant les crédits restants, rouge si < 3, tap → modal upgrade.
