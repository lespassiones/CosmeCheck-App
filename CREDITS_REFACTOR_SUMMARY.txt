   ✅ Reduced staleTime: 60s → 30s (faster cache invalidation)
   ✅ Added useEffect for polling cleanup
   ✅ New return values:
      - renewalPeriod: RenewalPeriod | null
      - renewalIntervalDays: number | null
   ✅ Error handling
   ✅ Manual refresh() function still available

Behavior:
  • On mount: fetch credits immediately
  • Every 10s: refetch in background (even if app is active)
  • Polling stops on unmount (cleanup in useEffect)
  • Admin changes detected within ~10 seconds
  • No visible loading/spinner, quiet update

Usage:
  ```typescript
  const {
    limit,
    remaining,
    renewalPeriod,
    renewalIntervalDays,
    refresh
  } = useCredits()

  // Display: "10 credits (weekly)"
  // Polling works automatically
  ```

Types:
  ```typescript
  interface UseCreditsReturn {
    credits: Credits | null
    remaining: number      // limit - used
    limit: number          // from tier or override
    used: number           // today's usage
    renewalPeriod: RenewalPeriod | null  // 'daily', 'weekly', etc.
    renewalIntervalDays: number | null   // 1, 7, 30, 365, null
    isLoading: boolean
    error: string | null
    refresh: () => void    // manual refetch
  }
  ```

Performance:
  ✅ Polling is lightweight (10s interval, not aggressive)
  ✅ staleTime 30s prevents excessive refetches when component re-renders
  ✅ RPC is fast (~40-50ms) due to index on user_id
  ✅ Memory: Single interval per app instance

================================================================================
  KEY FEATURES
================================================================================

Feature 1: Flexible Renewal Periods
  • Admin can set per-tier renewal: daily, weekly, monthly, yearly, one_time
  • Interval auto-calculated (1, 7, 30, 365, null)
  • Example: Free = 5 credits/week, Premium = 100 credits/month

Feature 2: User Overrides
  • Admin can give specific user custom credits
  • Overrides are soft-deleted (active=false) for audit trail
  • One override per user (unique constraint)
  • Persisted in separate table (not polluting user_profiles)

Feature 3: Real-time Mobile Sync
  • Mobile polling every 10 seconds
  • Admin change → mobile reflects within 10s
  • No app restart needed
  • Automatic, transparent to user

Feature 4: Admin Dashboard
  • 3 tabs for different workflows:
    1. Tiers: manage free/premium defaults
    2. Overrides: manage per-user exceptions
    3. Audit: view change history (stub ready)
  • Clean UI, inline editing
  • Toast notifications

Feature 5: Security
  • RLS policies prevent unauthorized access
  • Period validation in RPC (whitelist 5 values)
  • Audit trail via active flag + updated_at
  • Service-role-only admin RPCs

Feature 6: Type Safety
  • Full TypeScript typing on all new tables/RPCs
  • RenewalPeriod enum prevents invalid values
  • IDE autocomplete works
